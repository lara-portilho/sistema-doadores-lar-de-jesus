# Sistema de Doadores do Lar de Jesus

Este projeto é um sistema para gerenciamento dos doadores do centro espírita Lar de Jesus. Foi desenvolvido para manter as informações dos sócios organizadas e atualizadas, assim como as doações feitas, de modo a eliminar a necessidade do uso de papel. É um projeto beneficente e sem fins lucrativos.

## Stack utilizada

Projeto exclusivo em front-end, com backend sendo suprido pelo Firebase

**Linguagem:** Typescript

**Base:** Vite + React

**Bibliotecas:** Mobx, TailwindCSS, React Hook Form, React Icons, Sweet Alert, Toastify

# Lar de Jesus' Donors System

This project is a donor management system for the Lar de Jesus spiritualist center. It was developed to keep member information organized and up-to-date, as well as donations made, eliminating the need for paper. It is a charitable, non-profit project.

## Utilized stack

Exclusive front-end project, with backend being supplied by Firebase

**Language:** Typescript

**Base:** Vite + React

**Packages:** Mobx, TailwindCSS, React Hook Form, React Icons, Sweet Alert, Toastify
